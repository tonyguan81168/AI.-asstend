# 每日热点投研报告 Skill

## 流程

1. **抓数据**（仓库根目录执行）：
   ```bash
   python3 stock-research/fetch_hotspots.py            # 最近工作日
   python3 stock-research/fetch_hotspots.py --date 2026-09-25
   ```
   脚本默认日期只跳过周末，**不识别法定节假日**：先确认目标日是否休市（如中秋、国庆），休市则用 `--date` 指定最近交易日。
   韭研公社接口需登录：浏览器登录后复制请求头 Cookie，`export JYGS_COOKIE='...'` 再运行。
   同花顺涨停池里 `limit_up_type`（一字/换手/T字）和 `is_again_limit`（1=开板后回封）是一进二筛选的关键字段。
   输出 `stock-research/reports/<date>/raw.json`。读取其中 `errors`：
   - 部分源失败 → 继续，但在报告「数据说明」里写明缺哪个源。
   - 全部失败（常见于云端环境网络受限）→ 用 WebSearch 检索「财联社 <日期> 涨停复盘」「韭研公社 异动解析 <日期>」「同花顺 热股榜」等补充，并在报告中注明为二手来源。
   - 不得编造任何行情数字、涨停原因或公告；查不到就写「未获取」。
   - 搜索结果常混入往年同一天的数据（如 2023/2024 年的 9 月 25 日），逐条核对年份和指数点位后再用。
2. **识别主线**（见下方打分法），给出 1 条核心主线 + 1–2 条支线。
3. **选 3 只潜力股**（见下方筛选法），每只必须落在主线/支线内。
4. **按模板写报告**，保存到 `stock-research/reports/<date>/report.md`，并在对话中给出摘要。

## 主线识别打分（每个题材 0–10 分，加权合计）

| 维度 | 权重 | 数据来源 | 看什么 |
| --- | --- | --- | --- |
| 涨停家数 | 30% | 同花顺涨停池 `reason`、韭研 `jygs_action[].count` | 同一题材涨停 ≥5 家为强，≥10 家为主线级 |
| 连板高度 | 20% | 同花顺 `high_days`、韭研 `num` | 题材内最高板、是否有 2 板以上梯队（高-中-低） |
| 催化强度 | 25% | 财联社电报（加红/重要优先） | 政策/产业大事件 > 公司公告 > 传闻；是否有后续时间节点（发布会、会议、数据） |
| 市场关注度 | 15% | 同花顺热门概念、热股榜 | 板块热度排名、热股榜前 20 中该题材数量 |
| 持续性 | 10% | 结合近几日数据（有历史 raw.json 时对比） | 首日发酵 / 分歧转一致 / 高位退潮 |

合并同义题材（如「存储芯片」「HBM」「DRAM」归为一类）后再打分。

## 潜力股筛选（候选 = 主线/支线内个股）

优先级：
1. **身份**：龙头（最高板/最早封板）、中军（大市值趋势票）、补涨（低位首板但逻辑正宗）。三只尽量覆盖不同身份，分散风险。
2. **逻辑正宗度**：公司业务与题材直接相关（韭研/同花顺涨停原因可交叉验证），蹭概念的剔除。
3. **封板质量**：首封时间早、开板次数少、封单额/流通市值高。
4. **位置**：避开连续大幅上涨后的一字高位票（次日难买到、风险大），优先还有空间的 1–3 板或趋势中军。
5. **排除**：ST、*ST、新股未开板、近期有减持/问询/立案公告、当日炸板大面。

每只股票给出：代码、名称、所属主线、身份、入选逻辑（≤3 条）、关注点/观察条件、主要风险。
**不给出具体买卖价位承诺和收益预测。**

## 一进二模式（用户的打板规则）

用户说“一进二”“打板选股”时，候选池改为 **当日首板**，按以下顺序筛选 3 只：
1. **板块效应**：同题材当日 ≥2 只涨停，或有连板高标在前面带（例如高标 3 板 + 首板跟随）。孤立首板降级。
2. **逆势强度**：大盘/题材下跌时仍封板的优先（韭研异动解析的“原因”+ 同花顺涨停池 `first_limit_time` 早、`open_num` 少、`order_amount` 大）。
3. **催化**：有明确政策/产业消息优先；只有“题材跟风”的放备选。
4. **可买性**：一字或秒板的票次日难排上，优先换手充分后回封的首板；20cm 票注明需科创/创业板权限且容错更低。
5. **环境**：涨停 < 40 家或跌停多于涨停时，报告开头标注“一进二胜率低、轻仓”。

每只给出：明日介入条件（竞价/开盘表现）、同板块需观察的联动股、断板风险。输出保存为 `stock-research/reports/<date>/report.md`。
