# 每日热点投研报告 Skill

## 流程

1. **抓数据**（仓库根目录执行）：
   ```bash
   python3 stock-research/fetch_hotspots.py            # 最近工作日
   python3 stock-research/fetch_hotspots.py --date 2026-09-25
   ```
   脚本默认日期只跳过周末，**不识别法定节假日**：先确认目标日是否休市（如中秋、国庆），休市则用 `--date` 指定最近交易日。
   韭研公社接口需登录：浏览器登录后复制请求头 Cookie，`export JYGS_COOKIE='...'` 再运行。
   同花顺涨停池里 `limit_up_type`（一字/换手/T字）和 `is_again_limit`（1=开板后回封）是一进二筛选的关键字段。
   输出 `stock-research/reports/<date>/raw.json`。读取其中 `errors`：
   - 部分源失败 → 继续，但在报告「数据说明」里写明缺哪个源。
   - 全部失败（常见于云端环境网络受限）→ 用 WebSearch 检索「财联社 <日期> 涨停复盘」「韭研公社 异动解析 <日期>」「同花顺 热股榜」等补充，并在报告中注明为二手来源。
   - 不得编造任何行情数字、涨停原因或公告；查不到就写「未获取」。
   - 搜索结果常混入往年同一天的数据（如 2023/2024 年的 9 月 25 日），逐条核对年份和指数点位后再用。
2. **识别主线**（见下方打分法），给出 1 条核心主线 + 1–2 条支线。
3. **选 3 只潜力股**（见下方筛选法），每只必须落在主线/支线内。
4. **按模板写报告**，保存到 `stock-research/reports/<date>/report.md`，并在对话中给出摘要。

## 主线识别打分（每个题材 0–10 分，加权合计）

| 维度 | 权重 | 数据来源 | 看什么 |
| --- | --- | --- | --- |
| 涨停家数 | 30% | 同花顺涨停池 `reason`、韭研 `jygs_action[].count` | 同一题材涨停 ≥5 家为强，≥10 家为主线级 |
| 连板高度 | 20% | 同花顺 `high_days`、韭研 `num` | 题材内最高板、是否有 2 板以上梯队（高-中-低） |
| 催化强度 | 25% | 财联社电报（加红/重要优先） | 政策/产业大事件 > 公司公告 > 传闻；是否有后续时间节点（发布会、会议、数据） |
| 市场关注度 | 15% | 同花顺热门概念、热股榜 | 板块热度排名、热股榜前 20 中该题材数量 |
| 持续性 | 10% | 结合近几日数据（有历史 raw.json 时对比） | 首日发酵 / 分歧转一致 / 高位退潮 |

合并同义题材（如「存储芯片」「HBM」「DRAM」归为一类）后再打分。

## 潜力股筛选（候选 = 主线/支线内个股）

优先级：
1. **身份**：龙头（最高板/最早封板）、中军（大市值趋势票）、补涨（低位首板但逻辑正宗）。三只尽量覆盖不同身份，分散风险。
2. **逻辑正宗度**：公司业务与题材直接相关（韭研/同花顺涨停原因可交叉验证），蹭概念的剔除。
3. **封板质量**：首封时间早、开板次数少、封单额/流通市值高。
4. **位置**：避开连续大幅上涨后的一字高位票（次日难买到、风险大），优先还有空间的 1–3 板或趋势中军。
5. **排除**：ST、*ST、新股未开板、近期有减持/问询/立案公告、当日炸板大面。

每只股票给出：代码、名称、所属主线、身份、入选逻辑（≤3 条）、关注点/观察条件、主要风险。
**不给出具体买卖价位承诺和收益预测。**

## 一进二模式（用户的打板规则）

用户说“一进二”“打板选股”时，候选池改为 **当日首板**。

**硬性剔除（用户规则，必须先执行，不满足的一律不进名单，备选也不行）**：
- 最终封板时间（同花顺 `last_limit_time`）**晚于 10:30** → 剔除；
- **流通市值 < 30 亿**（同花顺 `market_cap`，即 currency_value）→ 剔除；
- 题材**没有政策支持**（国务院/国常会、部委规划或文件、地方政府方案），或**不属于当日主线**（涨停家数前列、同花顺热门概念前排）→ 剔除；
- **只选沪深主板**：代码以 600/601/603/605、000/001/002/003 开头；创业板 300/301、科创板 688/689、北交所（8/4/92 开头）一律剔除（用户无权限）；
- **必须有板块效应**：同题材当日主板涨停 ≥ 3 只（连板股也算），且该股涨停原因与题材直接相关；**孤立首板、只是跟风的单只首板**（题材里只有它一只，或业务和题材弱相关）→ 剔除；
- 一字板（次日基本买不到）→ 只列作“观察”，不作为候选。

报告中要列出“被剔除的热门首板及原因”，方便用户核对。剩下的按以下顺序排序，**输出最多 10 只合规首板组成的候选池表格**（代码、方向、首封→终封、开板次数、换手、流通市值、涨停原因、政策/主线依据），前 3 只给出详细分析；表格后附按题材分散、可买性（封死 vs 开板回封）、20cm 权限的选择建议。不足 10 只时如实列出，不凑数：
0. **封板时间越早越好**（2026-09-28 复盘：晋级的首板几乎都在 10 点前封板）；“是否回封”只作加分项。
1. **板块效应**：同题材当日 ≥3 只涨停，或有连板高标在前面带（例如高标 3 板 + 首板跟随）。孤立首板降级。
2. **逆势强度**：大盘/题材下跌时仍封板的优先（韭研异动解析的“原因”+ 同花顺涨停池 `first_limit_time` 早、`open_num` 少、`order_amount` 大）。
3. **催化**：有明确政策（国常会、部委规划）或产品涨价的优先；只是“蹭概念”（业务和题材弱相关）的放备选，用韭研原因核实业务相关度。
4. **可买性**：一字或秒板的票次日难排上，优先换手充分后回封的首板；20cm 票注明需科创/创业板权限且容错更低。
5. **环境**：涨停 < 40 家或跌停多于涨停时，报告开头标注“一进二胜率低、轻仓”。
6. **节假日**：次日是长假前最后一个交易日时，必须提示“持股过节、无法卖出”的风险。
7. **复盘**：每次先对照前一天的候选今天是否晋级，总结成败原因，再出新名单。

每只给出：明日介入条件（竞价/开盘表现）、同板块需观察的联动股、断板风险。输出保存为 `stock-research/reports/<date>/report.md`。

## 持仓次日竞价应对（每次出一进二名单时必须附上）

持仓记录在 `stock-research/holdings.json`（用户买入后告诉你就添加，卖出后删除；为空则跳过本节）。
对每只持仓，先用当日同花顺涨停池 / 热股榜数据确定它**今天的板型**，再按下表给出**明日 9:20–9:25 的具体动作**。

### 1. 先判断今天的板型
| 今日情况 | 判定 |
| --- | --- |
| 一字板 / 10:00 前封死、未开板、封单占流通 ≥ 2% | 强 |
| 10:30 前回封、开板 ≤ 2 次 | 中 |
| T 字板、烂板（开板 ≥ 3 次）、14:00 后才封死 | 弱：明日默认先卖一半 |
| 未涨停（冲高回落 / 收绿） | 弱：明日竞价不高开就全部卖出 |

### 2. 明日竞价应对表（按 9:25 竞价结果执行）
| 9:25 竞价 | 动作 |
| --- | --- |
| 高开 ≥ 5% 且竞价量能足 | 持有，看回封；冲高后跌破分时均价线就卖 |
| 高开 0–5% | 卖一半锁定利润，其余跌破昨日收盘价全卖 |
| 平开或低开（弱于预期） | 9:20–9:25 挂低价（可挂跌停价），竞价全部卖出 |
| 前一日为“弱”板型 | 不论竞价，先卖一半 |

### 2.5 竞价弱但板块强时（2026-10-08 传艺科技教训：低开 −0.8% 开盘卖出，5 分钟后弱转强封 3 板）
先看**同题材高标/同梯队的竞价**，再决定是否按上表卖出：
- 同题材连板股竞价一字或高开 ≥ 5%（如当日紫竹高科 3 板一字）、题材仍在热门概念前三 → **不在竞价/开盘第一分钟清仓**：
  - 只卖一半，或一股不卖、改用“开盘价 −2%”或“竞价最低价”作止损；
  - 观察 9:30–9:40：放量翻红、站上分时均价线 = 弱转强，持有；跌破开盘价且 5 分钟内收不回 = 卖出。
- 同题材也全线低开、无一字 → 按上表执行。
- 用户自己设的阈值（如“低开 −2% 才卖”）优先于本表；给建议时如要突破用户阈值，必须先说明理由并提示可能踏空。

### 3. 输出格式（每只持仓一段）
- **代码 名称**：成本 / 今日收盘 / 浮盈 %，今日板型与判定（附首封、终封、开板次数）
- **明日动作**：写成可以直接照做的句子，例如“9:25 竞价低于 +3%（约 X.XX 元），则 9:20 后挂跌停价 Y.YY 卖出全部”。按今日收盘价把百分比换算成具体价格。
- **条件单建议**：回落止盈（从最高回撤 5%）、保本止损（成本 +1%）的具体触发价。

### 4. 必须提醒的规则
- 竞价按统一开盘价成交，挂低价卖出也按开盘价成交；若开盘即跌停需排队，越早挂越靠前。
- 9:15–9:20 可撤单、多假单，以 9:20–9:25 为准。
- 次日为长假前最后一个交易日时，额外提醒持股过节风险，倾向于先卖一半。

## 打板成交技巧（2026-10-09：雄韬股份 09:31:03 秒封，用户 09:31:11 挂单未成交）
按候选的“前一日板型”给出对应的买法：
- **前一日秒板/封死型**（如雄韬）：次日大概率也是快速上板。人工在封死后挂单基本排不上。可选：
  ① **扫板**：涨到 +8%~+9% 且放量加速时，提前挂涨停价买入，吃掉卖盘成交，而不是等封死后排队；
  ② **竞价预埋**：竞价已高开 3%~5% 且高标竞价强时，9:20–9:25 挂涨停价买入，按开盘价成交（本质是竞价买入，需接受不封板风险）；
  ③ **云条件单**：股价 ≥ 涨停价 × 0.98 时自动以涨停价买入，服务器触发比手动快。
- **前一日开板回封型**（如丰元）：次日也常有开板，等开板后重新拉向涨停时挂单，成交率高。
- 每天候选旁边注明“建议买法”和提前算好的涨停价，用户前一晚把代码、数量、价格预填好。
- **模式外不买**：不在当日候选名单内的股票（尤其高位连板接力）一律不碰。
